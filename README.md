# C2DPost Web Edition

ระบบแปลงไฟล์ PDF สู่ตาราง Excel (.xlsx) และระบบจัดการบาร์โค้ดไปรษณีย์ไทย (PostOne) ในรูปแบบเว็บบราวเซอร์ พร้อมส่วนขยาย **C2DPost Helper Chrome Extension**

---

## 🌟 ฟีเจอร์หลัก
1. **ระบบ Extension Gating**: ตรวจจับว่าผู้ใช้ติดตั้งส่วนขยายหรือยัง หากยังไม่ติดตั้ง ระบบจะแสดงหน้าแนะนำให้ดาวน์โหลด `.zip` และคู่มือ 3 ขั้นตอน พร้อมตรวจจับอัตโนมัติเมื่อติดตั้งเสร็จ
2. **ข้ามข้อจำกัด IP ไปรษณีย์ไทย 100%**: การขอ Barcode ทำผ่าน Extension ในเครื่องผู้ใช้ (ซึ่งมี IP ประเทศไทย) ทำให้ไม่มีปัญหาเรื่องบล็อก IP จากต่างประเทศ และไม่มีปัญหา CORS
3. **ระบบ Drag & Drop PDF**: ลากไฟล์ PDF หลายไฟล์พร้อมกัน ระบบจะตัดคำภาษาไทย สกัดชื่อ ที่อยู่ รหัสไปรษณีย์ เบอร์โทรศัพท์ และเลขที่คำขอ
4. **Interactive Data Table**: ตารางพรีวิวข้อมูลที่สามารถค้นหา กรอง และคลิกแก้ไขข้อมูล (Inline edit) ได้โดยตรงก่อนพิมพ์
5. **การส่งออกเอกสาร**:
   - 📊 ดาวน์โหลดไฟล์ Excel (.xlsx) ตามเทมเพลต DPost
   - 📄 พิมพ์ใบนำส่ง (Delivery Note PDF)
   - 🏷️ พิมพ์เอกสารแนบบาร์โค้ด (Combined PDF)
   - ✉️ พิมพ์ซองจดหมาย (Envelopes PDF)
   - 📦 รวมชุดเอกสารทั้งหมดเป็นไฟล์เดียว (.ZIP)

---

## 🧩 วิธีติดตั้ง C2DPost Helper Extension (ครั้งเดียว)
1. ดาวน์โหลดไฟล์ `c2dpost-extension.zip` จากหน้าเว็บ หรือนำโฟลเดอร์ `extension/` ไปใช้งาน
2. แตกไฟล์ ZIP ออกมาเป็นโฟลเดอร์
3. เปิด Google Chrome ไปที่ `chrome://extensions`
4. เปิดสวิตช์ **"โหมดนักพัฒนา" (Developer mode)** ที่มุมขวาบน
5. กดปุ่ม **"โหลดส่วนขยายที่คลายการบีบอัดแล้ว" (Load unpacked)** แล้วเลือกโฟลเดอร์ `extension`
6. กลับมาที่หน้าเว็บ ระบบจะตรวจจับและปลดล็อกเข้าสู่ระบบทันที!

---

## 💻 วิธีการรันในเครื่อง (Local Run)
ดับเบิลคลิกที่ไฟล์ **`start_web.bat`**
ระบบจะ:
1. ติดตั้ง `npm install` ให้อัตโนมัติ (หากยังไม่มี `node_modules`)
2. เริ่มต้นรัน FastAPI Backend (Port 8000)
3. เริ่มต้นรัน Vite Frontend (Port 5173)
4. เปิดเบราว์เซอร์ไปยัง `http://localhost:5173` ทันที

---

## ☁️ วิธีการขึ้นระบบ Vercel (Cloud Deploy)
1. ติดตั้ง Vercel CLI หรือเชื่อมต่อ Git repository กับ Vercel
2. ในการตั้งค่าโปรเจกต์บน Vercel:
   - Framework Preset: **Vite**
   - Root Directory: `C2DPost_web`
   - Build Command: `npm run build`
   - Output Directory: `dist`
3. ไฟล์ `vercel.json` และโฟลเดอร์ `api/` จะทำหน้าที่เป็น Serverless Function สำหรับแปลงไฟล์ PDF ให้อัตโนมัติ
